# Goblins of the Ashborn Isles 0.5.7 - Oaths of Ash and Salt

- Ashen Covenant religion: six holy sites, eight traditions, Covenant Favor, three rites with a shared cooldown, twelve stories and the Moot of Six Fires.
- Named acceptance/refusal popups for Harbor Pact and Ashen Compact offers.
- AI no longer initiates the custom Harbor Pact; players retain access at the existing price.
- Foreign land starts undiscovered; nearby Atlantic waters remain known. Voyages reveal ports on return after the existing three-year opening delay.
- Goblin estate names, preserving native estate mechanics.
- Retains the 0.5.6 economy, situation panels, concise tooltips, named modifiers and Cindermaw council rewards.

## Installation

Targets EU5 1.3.11. Extract Goblins_Ashborn_Isles_0.5.7.zip into a new folder, close EU5 and run Install-Goblins.cmd. Enable one copy only and start a new 1337 campaign. No previous package is needed. Existing saves retain discovered land.

## Validation and limitations

Release gates cover the complete build, static references, terrain reconstruction, package hashes and clean-source isolated installation. Gameplay and balance remain unverified. Religion is a first pass: existing illustrations are reused, story rewards have limited differentiation, pilgrimage and damaged-site restoration are not implemented, and the native council action has no added cooldown. See RELIGION_057.md and TESTING.md. No confirmed crash-resolution claim is made.
