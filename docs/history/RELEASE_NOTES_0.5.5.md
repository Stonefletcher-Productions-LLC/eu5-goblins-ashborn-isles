# The Gathering of the Five

Unite five goblin kingdoms across six volcanic Atlantic islands, explore foreign
shores and secure a foothold on Europe's coast.

## What's new

- Two connected situations: the Gathering of the Five and Eastern Hunger.
- Seven diplomatic and military actions for alliances, paid aid, voluntary
  submission, war goals and fleet preparation.
- Five clan introductions, expanded ruler and dynasty stories, and Shatterfin's
  maternal-house follow-up. Existing family relationships and succession laws
  are preserved.
- Mixed Ashborn cultures in every district, bringing the starting population to
  1,618,696 across 72 districts.
- Seventeen original paintings covering all 21 authored events, plus custom
  headers and icons for both situations.
- Five custom clan flags matching the Gathering banners.
- A complete installer and a rewritten player guide. No earlier mod version is
  required.

## Install

1. Download **Goblins_Ashborn_Isles_0.5.5.zip** below and extract it completely.
2. Close EU5 and run **Install-Goblins.cmd** from the extracted folder.
3. Enable **Goblins of the Ashborn Isles**. Disable the separate **Gathering
   Prototype** add-on if you used it previously.
4. Restart EU5 and start a **new 1337 campaign**.

Built for **EU5 1.3.11**. Keep old saves separately. Other map, starting-world and
terrain shader mods may conflict.
